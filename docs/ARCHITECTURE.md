# 架构说明

## 业务域拆分

### 1. 认证与账户

- 登录
- 当前用户信息
- 权限与角色

### 2. 实时告警

- 告警流订阅
- 风险等级分布
- 最新交易明细

### 3. 检测工作台

- 单笔交易检测
- 批量文件检测
- OCR 结果接入
- 链路分析与处置建议

### 4. 报告中心

- 报告列表
- 报告详情
- 导出 PDF / HTML

### 5. 系统管理

- 模型版本
- 服务健康状态
- 系统配置

## 通信方式

- REST：查询、提交任务、拉取报告
- SSE：实时告警流

## 迁移策略

### 第一阶段

- 先搭新前后端骨架
- 旧模型通过适配层懒加载
- 使用模拟流支撑桌面端联调

### 第二阶段

- 接入 MySQL
- 接入 Kafka
- 接入 OCR
- 接入真实报表生成

### 第三阶段

- 加权限
- 加审计日志
- 加任务队列
- 加安装包流水线
